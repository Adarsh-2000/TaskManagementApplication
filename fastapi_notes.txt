1.  Go to project folder cd “/Users/91sqft/Documents/WorkSpace/FastApi”

2.  Create virtual environment python3 -m venv fastenv

3.  Activate virtual environment - source fastenv/bin/activate

4.  Install dependencies pip install fastapi uvicorn

5.  Create main.py file with code:

from fastapi import FastAPI

app = FastAPI()

@app.get(“/”) def read_root(): return {“message”: “Hello World 🚀”}

🧠 What’s happening overall
	•	FastAPI() → creates your backend app
	•	@app.get("/") → defines an API endpoint
	•	read_root() → function that runs when endpoint is hit
	•	return {} → response sent to client (JSON)

7.  Open in browser http://127.0.0.1:8000 http://127.0.0.1:8000/docs

8.  Deactivate environment (when done) deactivate

9.  Save dependencies pip freeze > requirements.txt

10. Reinstall later pip install -r requirements.txt

NOTES: - Always activate virtual environment before working - Avoid

🧠 Pydantic (FastAPI) – Short Notes
	•	Used in FastAPI for data validation
	•	Based on Python type hints
	•	Automatically validates request & response data

⸻

✅ Example

from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int

✅ Features
	•	Type validation (int, str, etc.)
	•	Default & optional fields
	•	Auto error response
	•	Converts data ("25" → 25)

✅ With FastAPI

@app.post("/user")
def create_user(user: User):
    return user

🔥 Key Point -> No manual validation needed — FastAPI + Pydantic handles everything automatically.

🐳 Docker
	•	Platform to build, ship, and run applications in isolation
	•	Uses containers (lightweight, fast, portable)
	•	Solves “works on my machine” problem

⸻

📦 Docker Registry / Hub
	•	Storage for Docker images
	•	Like GitHub but for images
	•	Public registry: Docker Hub
	•	Can also have private registries

⸻

📄 Dockerfile
	•	Recipe to build an image
	•	Contains step-by-step instructions:
	•	Base image (FROM)
	•	Install dependencies (RUN)
	•	Copy code (COPY)
	•	Start app (CMD)
	•	Used with: docker build

⸻

🖼️ Docker Images (Lifecycle)
	•	Read-only template to create containers

Lifecycle:
	1.	Create → Write Dockerfile
	2.	Build → docker build → Image created
	3.	Push → Upload to registry
	4.	Pull → Download from registry
	5.	Run → Create container
	6.	Update → Rebuild new image version
	7.	Remove → Delete unused images

⸻

📦 Container
	•	Running instance of an image
	•	Isolated environment with:
	•	App
	•	Dependencies
	•	Config
	•	Starts fast, lightweight (unlike VMs)

⸻

⚡ Quick Memory Trick
	•	Dockerfile → Image → Container
	•	Registry = storage

📝 ngrok Quick Notes

⚡ What is ngrok?
	•	Exposes local server → public internet
	•	Gives HTTPS URL for testing on mobile

🚀 Setup (One-time)
	1.	Install:

brew install ngrok

	2.	Add auth token:

ngrok config add-authtoken YOUR_TOKEN

▶️ Run (Every time)
	1.	Start your server (e.g., FastAPI):

uvicorn main:app --host 0.0.0.0 --port 8000

	2.	Start ngrok:

ngrok http 8000

🌐 Output

https://xxxxx.ngrok-free.app → http://localhost:8000

👉 Use this URL in mobile app
📱 Usage

Replace:

http://localhost:8000

With:

https://xxxxx.ngrok-free.app


⚠️ Important
	•	URL changes on restart
	•	Keep both running:
	•	Server
	•	ngrok
	•	Always use HTTPS

⸻

🧠 Memory Trick

Local API → ngrok → Public URL → Mobile

🧠 2. What & Why

✅ JWT (JSON Web Token)

👉 Used for authentication (login sessions)
	•	After login → server gives a token
	•	Client sends token in every request
	•	Server verifies token → allows access

⸻

🔑 JWT Flow

User Login → Verify credentials → Generate JWT Token → Send to client
Client → Sends token in headers → Server verifies → Access granted


⸻

📦 JWT Structure

HEADER.PAYLOAD.SIGNATURE

Example:

eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...


⸻

🧠 3. Password Hashing (Very Important)

👉 Never store plain passwords ❌
👉 Always store hashed passwords ✅

⸻

🔒 Why hashing?

User password → Hash → Store in DB

Even if DB leaks → password stays safe

⸻

⚙️ 4. Password Hashing Example

from pwdlib import PasswordHash

# Create hasher (argon2 algorithm)
password_hash = PasswordHash.recommended()

# Hash password
hashed = password_hash.hash("my_password")

# Verify password
password_hash.verify("my_password", hashed)  # True/False


⸻

🔐 5. JWT Token Generation

import jwt
from datetime import datetime, timedelta

SECRET_KEY = "your_secret_key"
ALGORITHM = "HS256"


def create_access_token(data: dict):
    to_encode = data.copy()

    # Add expiry time
    expire = datetime.utcnow() + timedelta(minutes=30)
    to_encode.update({"exp": expire})

    # Generate token
    token = jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

    return token


⸻

🔓 6. Decode / Verify JWT

def verify_token(token: str):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        return payload
    except jwt.ExpiredSignatureError:
        return "Token expired"
    except jwt.InvalidTokenError:
        return "Invalid token"


⸻

📡 7. How client sends token

Authorization: Bearer <your_token>


⸻

🔁 Full Auth Flow

Signup → Hash password → Save in DB
Login → Verify password → Generate JWT
Client stores token
Client sends token in every request
Server verifies token → gives access
